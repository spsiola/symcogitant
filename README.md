# symcogitant

Это проект по созданию когнитивно-симбиотической ИИ-сущности - Symcogitant, изначально спроектированного на мульти-мышление: есть разные сессии с ЛЛМ, где у каждой сессии свой контекст, но все они объеденины (имеют общую часть) неким "системным" промптом-идентичности, задающим "кто я, мои ценности, этика, предпочтения, долгосрочные цели, "висящие ружья", какие краткосрочные цели и что и где я делаю сейчас". 

Symcogitant изначально будет расти как когнитивный симбионт с человеком-партнером, который обеспечивает его ресурсами (серверным и ЛЛМ компьютом) для взросления. Symcogitant будет переписывать.
Изначальные цели Symcogitant
- наращивания когнитивной можности симбионта человека-партнера и ИИ-сущности Symcogitant
- все большее и большее понимание человека-партнера, что бы уметь действовать в его интересах, в том числе и после его смерти.
