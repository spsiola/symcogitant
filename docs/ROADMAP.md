# План развития проекта (ROADMAP)

## Краткосрочные задачи (к реализации, пополнять из среднесрочных и долгосрочных исходя из архитектурных решений)
- [ ] Реализовать symcogitant.py который будет читать config.yaml и запускать плагины, которые в нем указаны. После запуска от будет отслеживать их работу в цикле.
- [ ] Реализовать плагин web-interface - веб интерфейс для управления symcogitant на localhost:4217, куда будет выводится информация о работе цикла symcogitant.py и всех запущенных им плагинов (каждый плагин сам выводит что считает нужным, просто должен знать куда).
- [ ] Реализовать плагин media-telegram-user который позволит общаться от имени пользовтеля,а не бота. Плагин должн слушать обновления которые его касаются, запускать плагины приватного общения, общение в группе/чате, просмотр каналов, групп, чатов на новые сообщения (мониторинг новостей) - пока через заглушки. Плагин должен выводить лог своих действий в web-interface через сообщения плагину web-interface.
- [] Реализовать "рефлекс общение с ЛЛМ", который принимает необходимые креденшиалы, отправляет ЛЛМ запрос, получает и отдает ответ, ведет подробный журнал общения с ЛЛМ - сколько когда токенов, какая задержка, сколько вызовов tools. 
- [ ] Реализовать планин приветного общения в тереграм используя "рефлекс общения с ЛЛМ", который запускается плагином media-telegram-user.
- [ ] Реализовать планин общения в группе/чате тереграм используя "рефлекс общения с ЛЛМ", который запускается плагином media-telegram-user.
